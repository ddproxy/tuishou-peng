# Security Policy

## Supported Versions

Only the latest release is supported with security updates. Older releases are not maintained.

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/ddproxy/tuishou-peng/security/advisories/new). Do not open a public issue or pull request for a security problem.

Include the affected version, a description of the issue, and steps to reproduce it if available.

## Response Times

We aim to respond to reports within the following timeframes:

| Stage | Target response time |
| ----- | -------------------- |
| Acknowledgement | 2 business days |
| Initial assessment | 5 business days |
| Fix or mitigation plan | 10 business days |
| Release of a fix | As soon as the fix is verified |
